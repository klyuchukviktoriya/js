//! Запомнить
// Promise.all() → нужны все результаты.
// Promise.race() → нужен самый быстрый (успех или ошибка).
// Promise.allSettled() → дождаться всех, даже с ошибками.
// Promise.any() → нужен первый успешный результат.

// =========================================
// ASYNC / AWAIT — PRACTICE
// =========================================

// 1. Обработка ошибок
// --------------------
//
// Напиши функцию:
//
// async function divide(a, b) {}
//
// Если b === 0,
// выбрось ошибку.
//
// Вызови функцию через try/catch.

// =========================================
// 2. Загрузка пользователя
// =========================================
//
// Создай функцию:
//
// function getUser()
//
// Она должна вернуть Promise,
// который через 1 секунду вернёт:
//
// {
// id: 1,
// name: 'Vika'
// }
//
// Затем создай:
//
// async function showUser()
//
// Используй await,
// получи пользователя
// и выведи его в консоль.

// =========================================
// 3. Цепочка запросов
// =========================================
//
// Создай три функции:
//
// getUser()
// getPosts(userId)
// getComments(postId)
//
// Все должны возвращать Promise
// через setTimeout.
//
// Например:
//
// getUser()
// ->
// { id: 1, name: 'Vika' }
//
// getPosts(1)
// ->
// [
// { id: 10, title: 'Hello' }
// ]
//
// getComments(10)
// ->
// [
// 'Nice!',
// 'Cool!'
// ]
//
// Используй:
//
// - async/await
// - один try/catch
//
// Ожидаемый вывод:
//
// User: Vika
// Post: Hello
// Comments:
// - Nice!
// - Cool!

// =========================================
// 4. finally
// =========================================
//
// Напиши:
//
// async function loadData() {}
//
// Внутри:
//
// console.log('Loading...');
//
// Затем:
//
// либо верни данные,
// либо выбрось ошибку
// (на выбор).
//
// Но в finally
// обязательно вывести:
//
// Loading finished

// =========================================
// ОГРАНИЧЕНИЯ
// =========================================
//
// ✔ Только async/await.
// ✔ Только try/catch/finally.
// ✘ Не использовать then().

// =========================================
// 6. Promise.race()
// =========================================
//
// Создай функции:
//
// getUser() // 2000 мс
// getPosts() // 1000 мс
// getSettings() // 3000 мс
//
// Все возвращают Promise.
//
// В async функции:
//
// - используй Promise.race()
// - выведи результат в консоль.
//
// Какой результат должен прийти первым?

// =========================================
// 7. Promise.allSettled()
// =========================================
//
// Создай функции:
//
// getUser() -> resolve({ id: 1, name: 'Vika' })
// getPosts() -> reject(new Error('Posts error'))
// getSettings() -> resolve({ theme: 'dark' })
//
// Все через setTimeout.
//
// Затем:
//
// - используй Promise.allSettled()
// - выведи результат в консоль.
//
// Посмотри, чем отличаются объекты
// со status: 'fulfilled'
// и status: 'rejected'.

// =========================================
// 8. Promise.any()
// =========================================
//
// Создай функции:
//
// getUser() -> reject(new Error('User error'))
// getPosts() -> reject(new Error('Posts error'))
// getSettings() -> resolve({ theme: 'dark' })
//
// Все через setTimeout.
//
// Затем:
//
// - используй Promise.any()
// - выведи результат в консоль.
//
// После этого сделай так,
// чтобы ВСЕ три Promise завершались ошибкой,
// и посмотри, что попадет в catch.
