# GITHUB PRACTICE — BANK ACCOUNT

Создай класс BankAccount.

У экземпляра должны быть:

Свойства:

- owner
- приватное поле #balance

Методы:

- deposit(amount)
- withdraw(amount)
- getBalance()
- showInfo()

=========================================
ПРАВИЛА
=========================================

1. constructor(owner, balance)

Создаёт объект счёта.

Пример:

const account = new BankAccount('Vika', 1000);

=========================================

2. deposit(amount)

Добавляет деньги к балансу.

Если amount <= 0:
ничего не менять.

=========================================

3. withdraw(amount)

Снимает деньги.

Если amount <= 0:
ничего не менять.

Если amount больше текущего баланса:
вывести:

Not enough money

и не менять баланс.

=========================================

4. getBalance()

Возвращает текущий баланс.

=========================================

5. showInfo()

Выводит строку:

Vika: 1500 грн

=========================================
ПРОВЕРКА
=========================================

const account1 = new BankAccount('Vika', 1000);
const account2 = new BankAccount('Igor', 500);

account1.deposit(700);
account1.withdraw(200);

account2.withdraw(800);
account2.deposit(300);

account1.showInfo();
// Vika: 1500 грн

account2.showInfo();
// Igor: 800 грн

console.log(account1.getBalance());
// 1500

console.log(account2.getBalance());
// 800

=========================================
ДОПОЛНИТЕЛЬНАЯ ПРОВЕРКА ПРОТОТИПОВ
=========================================

Проверь:

console.log(account1.deposit === account2.deposit);

Должно быть:

true

Объясни себе, почему метод один,
а объекты используют его через прототип.

=========================================
ОГРАНИЧЕНИЯ
=========================================

- balance должен быть приватным через #balance
- не хранить balance как обычное свойство
- методы писать внутри class
- не использовать стрелочные функции как методы
- не писать готовое решение в комментариях
