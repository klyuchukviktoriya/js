# ЗАДАНИЕ: Транспорт

Создай три класса:

Vehicle
↓

Car

↓

ElectricCar

===========================
Vehicle
===========================

constructor(brand)

Свойство:

- brand

Метод:

getInfo()

Возвращает:

"Марка: Tesla"

===========================
Car
===========================

Наследуется от Vehicle

constructor(brand, model)

Добавляет:

- model

Переопределяет getInfo()

Возвращает:

"Марка: Tesla, модель: Model S"

===========================
ElectricCar
===========================

Наследуется от Car

constructor(brand, model, battery)

Добавляет:

- battery

(ёмкость батареи)

Переопредели getInfo()

Должно вернуть:

"Марка: Tesla, модель: Model S, батарея: 100 кВт"

===========================
Проверка
===========================

const tesla = new ElectricCar(
'Tesla',
'Model S',
100
);

console.log(tesla.brand);
console.log(tesla.model);
console.log(tesla.battery);

console.log(tesla.getInfo());

===========================
Ожидаемый результат
===========================

Tesla
Model S
100

Марка: Tesla, модель: Model S, батарея: 100 кВт

===========================
Правила
===========================

✔ Используй extends.

✔ Используй super() во всех конструкторах.

✔ Максимально переиспользуй методы.

✔ Не копируй код между классами.

✔ Подумай, где стоит использовать super.getInfo(), а где нет.
