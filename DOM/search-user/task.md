# FETCH — РАЗМИНКА

API:

https://jsonplaceholder.typicode.com/users

=========================================
ЗАДАНИЕ
=========================================

1. Получить пользователей с помощью fetch().

2. Проверить, что ответ успешный.

3. Преобразовать ответ в JSON.

4. Отобразить список пользователей.

=========================================
ДЛЯ КАЖДОГО ПОЛЬЗОВАТЕЛЯ ПОКАЗАТЬ
=========================================

Name:
Email:
Company:

Например:

---

Leanne Graham

Email:
leanne@...

Company:
Romaguera-Crona

---

=========================================
ДОПОЛНИТЕЛЬНО
=========================================

Добавь поле поиска.

Поиск должен работать
по имени пользователя.

Поиск выполняется
по кнопке Search.

=========================================
ОГРАНИЧЕНИЯ
=========================================

- Использовать async/await.
- Использовать try/catch.
- Не использовать then().
- Не делать повторный fetch при поиске.
- После получения данных хранить их
  в массиве users.

=========================================
БОНУС
=========================================

Если поиск ничего не нашёл,
вывести сообщение:

"No users found."

вместо пустого списка.
